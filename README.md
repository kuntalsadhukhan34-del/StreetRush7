# Street Rush 7 — MVP

Prototype flow:
Home → Map Selection → Matchmaking → 7 Racer Race → Result/Coin Reward
Home → Garage → Engine Upgrade

This is a starter Android Studio project. It is a gameplay/UI prototype, not yet the final 3D online multiplayer game.

Next development phases:
1. 3D car and track
2. Touch/tilt driving physics
3. Six maps
4. Real server matchmaking
5. Authoritative 7-player multiplayer
6. Persistent accounts/coins
7. Anti-cheat
8. Audio, VFX and Play Store release
